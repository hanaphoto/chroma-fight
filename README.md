# クロマファイト (chroma-fight)

クロマキー合成で「格闘ゲームの世界に入ったような写真」が撮れるWebアプリ（自分・知人向け試作）。
ブルー／グリーン／任意色のバックを抜いて、オリジナルのステージ背景・体力バー・文字演出と合成します。

## 機能

- 入力：カメラ撮影（getUserMedia、タイマー3/5/10秒、前/背面切替、PCはカメラ一覧、連写3枚）／写真取り込み（EXIF向き対応）
- ライブ合成プレビュー（低解像度・最大約720px幅）＋撮影後の高解像度本合成
- クロマキー：YCbCr色差＋しきい値＋フェザー（smoothstep）、スピル（色かぶり）除去は輪郭の半透明部中心
  - キー色：ブルー／グリーンプリセット、色ピッカー、スポイト（写真タップ）
  - スライダー：抜く強さ／境界のなめらかさ／色かぶり除去（プレイヤーごとに保持）
  - 確認用背景（白／黒／グレー／チェッカー／実際の背景）切替、抜く前／後比較
- 人数：1人／2人（一緒に1枚）／2人（別々に撮って対戦合成・人物レイヤー2枚）
- レイヤー：背景（cover）→人物1→人物2→体力バーHUD→文字演出。正規化座標（0〜1）で配置保持
  - 人物：ドラッグ移動、ピンチ＋スライダー拡大縮小、レイヤーごとの左右反転・ロック、立ち位置ガイド
- 背景：オリジナル生成サンプル4種（道場／市街地・ネオン／夕景／工業エリア、Canvas描画）＋自分の画像を追加可（IndexedDB保存）
- 体力バーHUD：Canvas描画ハイブリッド。名前・体力0〜100（ゲージ幅＋緑/黄/赤の色段階）・タイマー手動編集・K.O.表示（体力とは独立）。スタイル3種（クラシック／シンプル／ネオン）
- 文字演出：FIGHT!／K.O.／VS／ROUND 1／なし＋日付・イベント名
- 比率：16:9／4:3／9:16
- 出力：合成JPEG・元写真・抜きPNGを個別ダウンロード（`toBlob`、ファイル名 `chromafight_YYYYMMDD_HHmmss_比率.jpg`）、解像度は高画質（元基準）／軽量（長辺1280px）、印刷ボタン（印刷ビュー＋`window.print()`）
- 保存：小さな設定はlocalStorage、画像はIndexedDB。設定の書き出し／読み込み（JSON、version付き）
- PWA：`manifest.json`＋Service Workerでオフライン起動可。画面上に説明書（`manual.html`）リンクあり

## 使い方

`index.html` をブラウザで開く（カメラにはHTTPSまたはlocalhostが必要）。
詳しくはアプリ内の「説明書」リンク、または `manual.html` を参照。

ローカル確認例:

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## プライバシー

写真・追加画像・設定はすべて端末内（ブラウザ）だけで処理・保存され、**外部に送信されることはありません**。
外部フォント・外部CDN・アクセス解析は使用していません。

## 技術メモ / v1の割り切り

- 素のHTML/CSS/JavaScript＋Canvas 2Dのみ。ビルド不要。
- 抜き処理はメインスレッド。処理サイズは長辺最大2560pxに制限（メモリ対策）。
- 設定のZIP書き出し（設定＋画像）は未実装（v2候補）。書き出しは設定JSONのみ。
- スポイトは元写真プレビュー（cover表示）からのサンプルのため、比率が大きく違う場合は近似になります。
- サンプル背景・体力バー・文字はすべてオリジナル描画で、実在ゲームの素材は使用していません。
